# 🚀 Инструкция по деплою на GitHub Pages

## Шаг 1: Подготовка репозитория

1. Перейдите на [GitHub](https://github.com) и войдите в свой аккаунт
2. Убедитесь, что у вас уже есть репозиторий `phasma-boost`
3. Если репозитория нет, создайте новый:
   - Нажмите "New repository"
   - Название: `phasma-boost`
   - Сделайте публичным (Public)
   - Нажмите "Create repository"

## Шаг 2: Загрузка файлов

### Вариант A: Через веб-интерфейс GitHub

1. Откройте ваш репозиторий на GitHub
2. Нажмите "Add file" → "Upload files"
3. Перетащите все файлы проекта:
   - index.html
   - style.css
   - script.js
   - README.md
   - robots.txt
   - .gitignore
4. Напишите commit message: "Update website design"
5. Нажмите "Commit changes"

### Вариант B: Через Git (командная строка)

```bash
# Перейдите в папку с проектом
cd путь/к/вашему/проекту

# Инициализируйте Git (если еще не сделано)
git init

# Добавьте все файлы
git add .

# Создайте коммит
git commit -m "Update website design"

# Добавьте удаленный репозиторий (замените USERNAME на ваш username)
git remote add origin https://github.com/vfavfa72-cmd/phasma-boost.git

# Отправьте изменения
git branch -M main
git push -u origin main
```

## Шаг 3: Настройка GitHub Pages

1. Откройте ваш репозиторий на GitHub
2. Перейдите в **Settings** (Настройки)
3. В левом меню найдите **Pages**
4. В разделе "Source" (Источник):
   - Branch: выберите `main`
   - Folder: выберите `/ (root)`
5. Нажмите **Save** (Сохранить)
6. Подождите 1-2 минуты

## Шаг 4: Проверка

1. GitHub Pages покажет ссылку на ваш сайт:
   ```
   https://vfavfa72-cmd.github.io/phasma-boost/
   ```
2. Нажмите на ссылку или откройте её в браузере
3. Ваш новый сайт должен быть доступен!

## 🔄 Обновление сайта

Когда вы захотите обновить сайт:

### Через веб-интерфейс:
1. Откройте файл на GitHub (например, `index.html`)
2. Нажмите на иконку карандаша (Edit)
3. Внесите изменения
4. Нажмите "Commit changes"
5. Подождите 1-2 минуты - изменения появятся на сайте

### Через Git:
```bash
# Внесите изменения в файлы
# Затем:
git add .
git commit -m "Описание изменений"
git push
```

## 🎨 Кастомизация

### Изменить цвета:
Откройте `style.css` и измените значения в `:root`:
```css
:root {
    --primary: #6366f1;  /* Основной цвет */
    --secondary: #8b5cf6; /* Вторичный цвет */
    --accent: #ec4899;    /* Акцентный цвет */
}
```

### Изменить контакты:
Откройте `index.html` и найдите секцию с id `contact`

### Изменить цены:
Откройте `index.html` и найдите класс `.price-amount`

## 🐛 Решение проблем

### Сайт не отображается:
- Подождите 5-10 минут после первого деплоя
- Проверьте, что в Settings → Pages выбрана ветка `main`
- Убедитесь, что файл называется `index.html` (с маленькой буквы)

### Изменения не применяются:
- Очистите кэш браузера (Ctrl+Shift+R или Cmd+Shift+R)
- Подождите 1-2 минуты после push
- Проверьте, что коммит успешно загружен на GitHub

### Ошибка 404:
- Убедитесь, что файл `index.html` находится в корне репозитория
- Проверьте правильность URL

## 📞 Поддержка

Если возникли проблемы:
1. Проверьте вкладку "Actions" в репозитории на наличие ошибок
2. Убедитесь, что все файлы загружены правильно
3. Попробуйте отключить и снова включить GitHub Pages
