# 👻 PhasmaBoost - Профессиональная прокачка аккаунтов

Современный лендинг для услуг буста в Phasmophobia.

## 🎨 Особенности дизайна

- **Современный темный дизайн** с неоновыми акцентами
- **Плавные анимации** и переходы
- **Полностью адаптивный** дизайн для всех устройств
- **Оптимизированная производительность**
- **Интерактивные элементы** с эффектами наведения

## 📋 Структура сайта

### Секции:
1. **Hero** - Главный экран с призывом к действию
2. **Features** - Ключевые преимущества услуг
3. **Services** - Пакеты прокачки с ценами
4. **Process** - Пошаговый процесс работы
5. **Reviews** - Отзывы клиентов
6. **Contact** - Контактная информация

## 🚀 Как использовать

### Локальный просмотр:
1. Откройте файл `index.html` в браузере
2. Или используйте локальный сервер:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js (если установлен http-server)
   npx http-server
   ```

### Деплой на GitHub Pages:
1. Создайте репозиторий на GitHub
2. Загрузите файлы в репозиторий
3. Перейдите в Settings → Pages
4. Выберите ветку `main` и папку `root`
5. Сохраните настройки

## 📝 Настройка контента

### Изменить контактные данные:
Откройте `index.html` и найдите секцию `#contact`:
- Discord: измените ссылку и username
- FunPay: измените ссылку на ваш профиль

### Изменить цены:
Найдите секцию `.services-grid` и обновите значения в `.price-amount`

### Добавить отзывы:
Скопируйте блок `.review-card` и измените содержимое
