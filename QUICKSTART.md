## ✏️ Быстрые изменения

### Изменить Discord и FunPay
Откройте `index.html`, найдите (Ctrl+F):
- `vafge_50913` - замените на ваш Discord
- `https://funpay.com/users/19575364/` - замените на вашу ссылку

### Изменить цены
Откройте `index.html`, найдите `.price-amount` и измените цены:
```html
<span class="price-amount">от 500₽</span>
```

### Изменить цвета
Откройте `style.css`, найдите `:root` и измените:
```css
--primary: #6366f1;    /* Основной цвет */
--secondary: #8b5cf6;  /* Вторичный цвет */
```
